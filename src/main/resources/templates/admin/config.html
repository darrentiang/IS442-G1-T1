Matching configuration

Matching works when it gets three things right. Each tab controls one of them.

Quality: matches are good for both people

Each student's fit is scored from their own preferences, using the criteria and weights below. The two fits are combined with the harmonic mean, so a match that suits one person but not the other scores low.

Spread: requests don't pile onto a few students

Without this, a few popular students get every request while others get none. The congestion penalty moves students who already have requests waiting down other people's lists, so new requests spread out.

Reach: as many students as possible get a real match

A student with too few good matches sees BOSS Advisor on Find buddies: the one preference change that would win back the people who almost matched them, checked with the real engine first.
